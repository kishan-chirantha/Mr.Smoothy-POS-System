# 🍹 Mr. Smoothy POS System

A desktop-based Point of Sale (POS) system developed using Java SE for restaurant management. The application provides role-based access for administrators and cashiers, enabling efficient sales processing, employee management, product management, reporting, and automated invoice generation.

## 📖 Overview

Mr. Smoothy POS System is designed to simplify restaurant operations by digitizing sales transactions and administrative tasks. The system offers separate interfaces for Admin and Cashier users, ensuring secure and organized workflow management.

## ✨ Key Features

### 🔐 User Authentication

* Secure login system
* Role-based access control
* Separate Admin and Cashier dashboards

### 👨‍💼 Admin Module

* Manage employees
* Manage products and inventory
* Monitor sales records
* View business performance reports
* Generate and analyze reports

### 🛒 Cashier Module

* Process customer orders
* Add products to cart
* Calculate bills automatically
* Complete sales transactions
* Generate customer invoices

### 📄 PDF Invoice Generation

* Automatically generates invoices after purchase
* Includes purchased items, quantities, prices, and totals
* Provides a professional PDF format for customer records

## 🚀 Installation & Setup

### Prerequisites

* Java JDK 8 or later
* MySQL Server
* NetBeans IDE (Recommended)

### Clone the Repository

```bash
git clone https://github.com/kishan-chirantha/Mr.Smoothy-POS-System.git
```

### Configure Database

1. Create a MySQL database.
2. Import the provided SQL file.
3. Update database connection settings in the project.

### Run the Application

1. Open the project in NetBeans IDE.
2. Build the project.
3. Run the application.
